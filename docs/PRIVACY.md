# 数据与隐私

程序在本地打开、编辑和保存用户选择的文件，没有实现文档上传或遥测功能。

## 本地数据

日常运行时，WebView2 配置、字号主题偏好和恢复草稿保存在当前用户的 `%LOCALAPPDATA%/InkPageMarkdown`。恢复草稿可能包含尚未保存的正文和文件路径，请按个人数据保管。

`--self-test` 使用构建输出旁的 `.test-output/`，与日常运行数据隔离。仓库忽略草稿、浏览器配置、缓存、测试输出、下载的 SDK 和生成的二进制文件。

源码中的 `%LOCALAPPDATA%` 是由系统在运行时解析的通用位置；仓库不包含任何人的实际浏览器配置或草稿。

## 网络与链接

构建脚本首次运行时只为恢复 SDK 访问 NuGet 官方源。程序界面使用打包的本地 JavaScript 与 CSS；`inkpage.local` 和 `document.local` 是 WebView2 的虚拟本地资源映射。

默认不加载远程图片。点击外部链接时，程序会询问是否通过默认应用打开。WebView2 Runtime 的安装和更新遵循微软运行时自身的行为。

## 发布范围

仓库仅维护源代码、通用示例、必要静态资源、构建脚本和项目文档。个人笔记、系统账号信息、凭据、本机工作区配置、业务文档和用户截图不属于项目源码。
