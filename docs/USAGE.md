# 使用说明

从 `dist/InkPage/InkPage.exe` 启动程序。文件信息或工具栏空白处可拖动窗口，双击可最大化 / 还原；右上角提供窗口控制。

## 阅读与编辑

顶部可切换阅读、双栏和编辑。点击目录可以跳转章节；字号选项调整正文大小，主题按钮切换深色与浅色。

滚动条默认透明。鼠标移动、滚轮和键盘滚动时显示，停止活动约一秒后隐藏；滚动条显示不会改变排版宽度。键盘导航、触摸和系统高对比度环境保留必要的可见提示。

## 文件

点击打开或按 Ctrl+O 选择 Markdown / 文本文件。关闭、新建或打开其他文档前，若当前内容有修改，程序会询问是否保存。

Ctrl+S 保存，Ctrl+Shift+S 另存为。若文件已被其他程序修改，会提示另存，避免直接覆盖。异常退出后，下次启动可恢复本地草稿。

更多菜单提供 PDF 和 HTML 导出。阅读视图是连续纸张式显示；PDF 导出使用 A4 自动分页并隐藏工具栏。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| Ctrl+N / Ctrl+O | 新建 / 打开 |
| Ctrl+S / Ctrl+Shift+S | 保存 / 另存为 |
| Ctrl+P | 导出 PDF |
| Ctrl+F | 查找 |
| Enter / Shift+Enter（查找框） | 下一处 / 上一处 |
| Ctrl+B / Ctrl+I | 粗体 / 斜体 |
| Ctrl+Z / Ctrl+Y | 撤销 / 重做 |
| Tab（编辑区） | 插入两个空格 |
| Esc | 关闭查找及更多菜单 |
