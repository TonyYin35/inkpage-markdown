# 给文字，一页安静的空间。

欢迎来到 **墨页**。这是一个本地 Markdown 阅读与编辑工具：保留纯文本的轻便，也让阅读像翻开一份排版整齐的文档。

> 从一段文字开始。整理思路、记录灵感，让内容本身成为主角。

## 01 · 开始使用

点击顶部工具栏的 **打开**，选择你的 `.md`、`.markdown` 或 `.txt` 文件。文件保留在本机，日常使用无需联网。

- **阅读**：将 Markdown 排成一页纸，专心读内容。
- **双栏**：左边写源文本，右边实时查看排版。
- **编辑**：留出完整的写作空间，支持撤销与常用快捷键。

点击左侧目录可以跳到对应章节；上方的 **字号** 选项可以调整阅读字号，旁边的按钮切换深色主题。

## 02 · 用简单的语法表达

用 `#` 标记标题，用 `**文字**` 强调重点。你也可以写 *斜体*、~~删除线~~，或者在段落中放一段 `行内代码`。

### 让记录更有条理

- [x] 体验纸张式阅读

### 表格与代码

| 场景 | 推荐模式 | 常用操作 |
| --- | --- | --- |
| 读长文、看笔记 | 阅读 | 点击目录跳转 |
| 边写边看效果 | 双栏 | Ctrl + S 保存 |
| 专心写作 | 编辑 | Ctrl + B 粗体 |

## 03 · 保存与分享

按 **Ctrl + S** 保存源文件。更多菜单 **•••** 中可以另存为，也可以导出 PDF 或 HTML 阅读版。

PDF 导出会使用 A4 纸张自动分页，去掉工具栏和目录侧栏，保留正文的标题、表格与代码。
